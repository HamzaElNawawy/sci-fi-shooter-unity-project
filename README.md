Sci-Fi Shooter Game – Unity Project

A sci-fi third-person shooter game created in Unity as a university media interaction project.

The game includes player movement, aiming, shooting, enemy waves, moving enemies, healing pickups, health systems, a boss fight, sound effects, animations, UI feedback, and a skippable intro video.

Project Concept

The project focuses on interactive media feedback in a shooter game environment.

Player actions such as moving, aiming, shooting, taking damage, healing, and defeating enemies are connected to visual, audio, animation, and UI responses.

The game progression is based on completing objectives:

Level 1: Destroy targets
Level 2: Defeat stationary enemies
Level 3: Defeat moving enemies
Boss Fight: Defeat the final boss

Interaction Design
Player Movement

The player can move around the sci-fi station using keyboard input. Movement is connected to character animation and camera movement.

Aiming and Shooting

The player can aim using right click. The camera zooms in, a dark scope overlay appears, and the crosshair remains visible for accurate aiming.

Shooting uses bullets, raycasting, gun sounds, muzzle flash, and hit detection.

Health and Damage

When the player is hit by enemies, the health bar decreases and a damage sound plays.

Enemies also have red health bars that decrease when they take damage.

Healing Pickups

Healing items are placed around the map. When the player touches a healing item, the player gains health and the pickup disappears.

Level Progression

The game uses a progress system:

Destroy all Level 1 targets → Level 2 starts
Destroy all Level 2 enemies → Level 3 starts
Destroy all Level 3 enemies → Boss fight starts
Destroy boss → Game completed

Boss Fight

After Level 3, the boss fight begins. The UI changes to "BOSS FIGHT" and the player must defeat the final mech boss.
